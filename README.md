A single painfully honest — yet still polite — out-of-office auto-reply for make.fun's "The Painfully Honest Out-of-Office" competition: one sentence that admits the sender is dreading the return because of the unread-email pile-up, while thanking the reader for their patience.

## Run it

```sh
node main.ts
```

This writes the reply to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program fails loudly if the reply ever leaves the 1–200 character gate or stops being exactly one sentence.
